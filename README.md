# 🔥 CollBomber API Server
Remote API server for CollBomber Telegram Bot.

## Deployment
1. GitHub repo ko Render se connect karo
2. Auto deploy ho jayega

## Environment Variables
- `API_PORT` - Server port (default: 5000)
- `API_AUTH_TOKEN` - Auth token for API access
- `BOT_TOKEN` - Telegram bot token (optional)
